# (New UI) Export objective configurations

*Beta feature*

Export the configurations of one or more objectives to [!DNL Microsoft Excel] worksheet files. The configuration for each objective includes each metric and its source, the metric type (goal or assist), the non-mobile and mobile weights, and the reommended non-mobile and mobile weights.

When you export multiple objectives, the export consists of a ZIP file with a separate worksheet for each objective.

1. In the main menu, click **[!UICONTROL Goals] > [!UICONTROL Objectives]**.

1. Select the check box next to each objective to export.

1. In the bulk actions toolbar, click **[!UICONTROL Export Objectives]**.
