# About this guide

Information about specific groups of tasks and other information are available in the following help chapters:

* "Introduction" introduces the main features of Advertising Search, Social, & Commerce.

* "Getting started" explains the major tasks involved in an advertiser implementation, from setting up for the initial launch to performing ongoing management tasks; and how the user interface is organized.

* "Common tasks" explains how to configure the various performance data views based on your information needs and preferences, how to manage custom metrics, how to manage alerts and notifications, and how to perform other common tasks.

* The following chapters explain functionality for the main menu options in the new user interface: "[!UICONTROL Dashboard]," "[!UICONTROL Manage]," "[!UICONTROL Reports]," [!UICONTROL Plan]," "[!UICONTROL Setup]," '[!UICONTROL Goals]," "[!UICONTROL Targeting]," and "[!UICONTROL Library]."

  For details about each chapter, see "[How the user interface is organized](/help/search-social-commerce/getting-started/user-interface.md)."

* "Tracking" explains how to set up click and conversion tracking for your ads and keywords.

* "Legacy user interface" explains tasks you can perform in the [legacy user interface](help/search-social-commerce/getting-started/ui-switch.md).

   Most of these tasks are also available in the new user interface.

>[!NOTE]
>
>Additional help on optimization, including using portfolios for bidding in the legacy user interface, is available from the [!UICONTROL Help] menu (![Help menu](/help/search-social-commerce/assets/help-main-menu.png "Help menu")) in the upper right of any page within Search, Social, & Commerce.
