# C2PA metadata in [!UICONTROL Creative Studio]

[!UICONTROL Creative Studio] automatically attaches C2PA metadata to content that's generated or edited with generative AI, so that the provenance of your ad content is recorded as durable, invisible metadata. The metadata follows the standard of the [Coalition for Content Provenance and Authenticity](https://c2pa.org/) (C2PA).

## Content types and their scope {#cc-content-types}

| Content type | Supported? | AI service that generates the content | Model that generates the credential |
| --- | --- | --- | --- |
| Images | Yes. C2PA metadata is attached when images are generated or edited with generative AI, and preserved through cropping and resizing operations performed by AI Assistant. | Adobe Firefly | Google Gemini Flash |
| Text | &mdash; Text-only outputs of AI Assistant, such as copy generation, don't require C2PA metadata. | &mdash; | &mdash; |

## Actions that attach C2PA metadata

The following table summarizes when C2PA metadata is attached, based on the image action performed in the [!UICONTROL Creative Studio] AI Assistant.

| Action | Description | C2PA metadata attached? | Use case example |
| --- | --- | --- | --- |
| **Generate an image** | Create a new image using a text prompt | Always, because the image is generated by generative AI. | You use a text prompt to generate a new background image or logo for an ad template.<br><br>You use a text prompt to replace the default image in an ad concept with an uploaded asset from your library.<br><br>You use a text prompt to generate variations of a background image in an ad template. |
| **Crop an image** or **resize an image** | Adjust an image to requested dimensions using a text prompt | Cropping or resizing an uploaded image from a text prompt adds C2PA metadata.<br><br>Cropping or resizing a generated image without applying any non-AI edits (such as text overlays or drawing), so that the updated image is considered fully generated, adds C2PA metadata. | You use a text prompt to crop an uploaded background image in an ad concept: C2PA metadata is added.<br><br>You use a text prompt to resize a generated background image in an ad concept: C2PA metadata is added.<br><br>You use a text prompt to crop a background image in an ad concept and then add a text overlay: No C2PA metadata is created. |

## What happens as your content moves? {#cc-content-moves}

The full provenance chain is preserved when a user downloads an image file or it is sent to be served in an ad.

## What does the C2PA metadata include?

For each GenAI generation or alteration, the following are included in the C2PA metadata. If an asset is altered multiple times, then each operation appears in the C2PA metadata.

* Name and version information of the AI system used (Adobe Firefly) 
* AI model used (Adobe Firefly) <!-- gemini-flash for images -->
* Usage: Whether it was generated or edited using GenAI 
* Time and date of content creation and/or modification with generative AI tools 
* Unique identifier (which can be used to distinguish each use of Generative AI) 

## How can I view C2PA metadata for an image?

To see the complete asset history for an image,

* Open the image file in a content authenticity inspection tool, such as https://contentauthenticity.adobe.com/inspect or https://verify.contentauthenticity.org/.

* View the image metadata.

* View the image code using your browser's code inspection tool (often called [!DNL Inspect]).
