# C2PA metadata in [!UICONTROL Creative Studio]

[!UICONTROL Creative Studio] automatically attaches C2PA metadata to content that's generated or edited with generative AI, so that the provenance of your ad content is recorded as durable, invisible metadata. The metadata follow the standard of the [Coalition for Content Provenance and Authenticity](https://c2pa.org/) (C2PA).

## Content types and their scope {#cc-content-types}

| Content type | Supported? | AI service that generates the content | Model that generates the credential |
| --- | --- | --- | --- |
| Images | Yes. C2PA metadata is attached when images are generated or edited with generative AI, and preserved through cropping and resizing operations performed by AI Assistant. | Adobe Firefly | Google Gemini Flash |
| Text | &mdash; Text-only outputs of AI Assistant, such as copy generation, don't require C2PA metadata. | &mdash; | &mdash; |


## Actions that attach C2PA metadata

The following table summarizes when C2PA metadata is attached, based on the image action performed in the [!UICONTROL Creative Studio] AI Assistant.

| Action | Description | C2PA metadata attached? | Use case example |
| --- | --- | --- | --- |
| **Generate an image** | Create a new image using a text prompt | Always, because the image is generated by generative AI. | You use a text prompt to generate a new background image or logo for an ad template.<br>You use a text prompt to replace the default image in an ad concept with an uploaded asset from your library.<br>You use a text prompt to generate variations of a background image in an ad template. |
| **Crop an image** or **resize an image** | Adjust an image to requested dimensions using a text prompt | Cropping or resizing an uploaded image from a text prompt adds C2PA metadata.<br>Cropping or resizing a generated image without applying any non-AI edits (such as text overlays or drawing), so that the updated image is considered fully generated, adds C2PA metadata. | You use a text prompt to crop an uploaded background image in an ad concept: C@PA metadata is added.<br>You use a text prompt to resize a generated background image in an ad concept: C2PA metadata is added.</br>You use a text prompt to crop a background image in an ad concept and then add a text overlay: No C2PA metadata is created. |
| **Add a text overlay** | Layer generated text on top of a background image using a text prompt | Only if the background image already had C2PA metadata. Adding the overlay produces a new image from the background plus the text. The overlay step doesn't add a new generative AI action. | You use a text prompt to add a promotional headline as a text overlay over a background image in an ad concept: The C2PA metadata from the background image is preserved. |
| **Overlay images** | Composite two or more images together using a text prompt | Compositing produces a new image from the sources. If any of the source images have C2PA metadata, then the combined image carries C2PA metadata that includes each source that contributed a generative AI action. | You use a text prompt to composite a generated product image with a generated background for an ad: The composite image carries C2PA metadata that indicates both generative AI sources. |

## What happens as your content moves {#cc-content-moves}

The full provenance chain is preserved when a user downloads an image file or it is sent to be served in an ad.

## When does the C2PA metadata include, and how can I view it?

For each GenAI generation or alteration, the following are included in the C2PA metadata. If an asset is altered multiple times, then each operation appears in the C2PA metadata.

* Timestamp (date + time)
* Model name + version (Adobe Firefly / gemini-flash for images<!-- ; Anthropic claude-sonnet-4-5 for text -->)
* Unique identifier (UUID per operation)

Learn more about [C2PA metadata created using Adobe Firefly](https://helpx.adobe.com/firefly/using/content-credentials.html){target="_blank"}.

To see the complete asset history for an image,

* Open the image file in a content authenticity inspection tool, such as https://contentauthenticity.adobe.com/inspect or https://verify.contentauthenticity.org/.

* View the image metadata.

* View the image code using your browser's code inspection tool (often called [!DNL Inspect]).
